# AXON — website

The download page for **AXON**, a free Windows study app that turns your course materials into summaries, flashcards, practice tests and more using a private AI that runs on your own PC.

**Website:** https://arkspec-studio.github.io/axon/
**Download:** see [Releases](https://github.com/ArkSpec-Studio/axon/releases).

This repository holds only the static website. It has no server, database or forms, loads nothing from third-party sites, and runs under a strict Content-Security-Policy.
